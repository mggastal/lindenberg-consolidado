# lindenberg-consolidado

## Apresentação do comitê dentro do painel Obs

`python3 atualizar_reuniao.py ... --comite DDmmmAAAA-comite.html` copia o HTML da apresentação (gerado por `Lindenberg/Apresentacao/gerar_comite_html.py` a partir do deck) e embute o visualizador no painel **Obs** daquela reunião. O bloco só entra quando o parâmetro é passado; nas semanas seguintes ele sai sozinho.
